# Gochisou TikTok — แนวทางโพสต์ (draft 5 ก.ย. 69)

> บทบาท: พี่เจ = คิดคอนเทนต์/เพิ่มไอเดีย (AI ตัวอื่นช่วยได้) · พาเที่ยว = สร้างคลิป + โพสต์
> ใช้กับ Gochisou (B2C, @gochisou_booking) และ reuse เทคนิคกับ ichinotour (B2B — สถานที่/Itinerary)
> ระบบผลิต: [[Gochisou_TikTok_3Layer]] · คลังอ้างอิง: [[TikTok_AI_Library]]

## หลักการ

- **ของจริง + AI ขยับ** ไม่ใช่ AI ล้วน (กัน "ดู AI"): รูปอาหาร/ร้าน/โลโก้จริง เอามาเป็นฐาน แล้วใช้ GeoVisualizer/CapCut ขยับมุม + VO
- Voiceover ไทยได้แล้ว (pipeline Gemini TTS charon) → คลิปมีคนพูด = เก็บคนดู
- เนื้อหาต้องตรงความจริง (ราคา/บริการ/เวลา — ห้ามเกินจริง; ข้อเท็จจริงใน scripts batch1)

## เนื้อหา 3 แบบ (คอนเทนต์ผสมในฟีด)

| แบบ | ตัวอย่าง | เครื่องมือ | ใช้ทำ |
|---|---|---|---|
| 1. อาหาร/ร้านจริง | omakase วางโกลด์ลีฟ, ชาบู, ยากินิกิ | ภาพจริง + VO + CapCut | ขายตรง ลูกค้าเห็นของจริง |
| 2. สถานที่/มุมโดรน | บินวนย่าน/หน้าร้านดังโตเกียว | GeoVisualizer (จากรูป) | Hook เปิดหัว + B-roll — โกชิโซ + ichinotour Itinerary |
| 3. ปัญหา → ทางออก | "ร้านดังจองยาก" / "AI ออกกล้องอธิบาย" | avatar CapCut + VO | Top-funnel ดึงคนที่ไม่รู้จักบริการ |

## ความถี่ + เวลาโพสต์

- เริ่ม Batch 1 (5 คลิป) ให้ครบก่อนค่อยเพิ่ม — เป้า 3-5 คลิป/วัน
- เวลาญี่ปุ่น: มื้อเที่ยง ~11:00-13:00 JST, เย็น ~18:00-21:00 JST (คนหาเรื่องกิน)
- ทุกคลิปจบ CTA: ทัก LINE https://line.me/ti/p/30vpsvVCjS · เว็บ https://gochisou.ichinotour-thailand.com
- ลง 2 แชแนลถ้าเนื้อหาเข้ากัน: Gochisou B2C (อาหาร) + ichinotour B2B (สถานที่/Itinerary)

## QC ก่อนโพสต์

- เนื้อหาตรงข้อเท็จจริง (ราคา 3,000/5,000 JPY เงื่อนไข) — ไม่อ้าง "จองได้ทุกที่ 100%"
- เสียง/ซับตรง, สี/ความคม, 9:16
- คลิปแรกๆ พี่เจ้าดูผ่านก่อน — พอ pattern เข้าแล้วพาเที่ยวโพสต์ได้เอง
