# Gochisou TikTok — แนวทางโพสต์ + พรีเซนเตอร์ (5 ก.ย. 69)

> บทบาท: พี่เจ = คิดคอนเทนต์/เพิ่มไอเดีย (AI ตัวอื่นช่วยได้) · พาเที่ยว = สร้างคลิป + โพสต์
> ใช้กับ Gochisou (B2C, @gochisou_booking) และ reuse เทคนิคกับ ichinotour (B2B — สถานที่/Itinerary)
> ระบบผลิต: [[Gochisou_TikTok_3Layer]] · คลังอ้างอิง: [[TikTok_AI_Library]]

## หลักการ

- **ของจริง + AI ขยับ** ไม่ใช่ AI ล้วน (กัน "ดู AI"): รูปอาหาร/ร้าน/โลโก้จริง เอามาเป็นฐาน แล้วใช้ GeoVisualizer/CapCut ขยับมุม + VO
- Voiceover ไทยได้แล้ว (pipeline Gemini TTS charon) → คลิปมีคนพูด = เก็บคนดู
- เนื้อหาต้องตรงความจริง (ราคา/บริการ/เวลา — ห้ามเกินจริง; ข้อเท็จจริงใน scripts batch1)

| แบบ | ตัวอย่าง | เครื่องมือ | ใช้ทำ |

| 2. สถานที่/มุมโดรน | บินวนย่าน/หน้าร้านดังโตเกียว | GeoVisualizer (จากรูป) | Hook เปิดหัว + B-roll — โกชิโซ + ichinotour Itinerary |
