## ภารกิจ

ออกแบบหน้า landing ใหม่สำหรับบริการ "Gochisou by Ichinotour" — บริการรับจองร้านอาหารทั่วญี่ปุ่น (โตเกียว/โอซาก้า/ฮอกไกโด/เกียวโต) ให้กับกรุ๊ปทัวร์/เอเจนซี่/ไกด์/แก๊งเพื่อน. มี landing ต้นแบบอยู่แล้ว (HTML + Tailwind) ต้องการให้ช่วยออกแบบมุมมองใหม่ + เลือกใช้ภาพที่ให้ไปให้คุ้มสุด.

## สิ่งที่อยากได้จาก Omni/Flow

1. **แนะนำโครงสร้าง landing ใหม่** — ใช้ภาพไหนตรงส่วนไหน (hero/gallery/เมนู/social proof) + เหตุผล
2. **Copy ใหม่** — headline/subhead ไทยที่สั้นกระทบ 3-5 แบบ ให้เลือก
3. **ถ้าทำวิดีโอสั้น (Omni)** — สคริปต์คลิปโปรโมต 15-30 วิ 1 ตัว (B2B เอเจนซี่ทัวร์ + B2C นักท่องเที่ยว) ใช้ภาพที่มี
4. **ข้อจำกัด:** พี่เจจะเอาไปใส่ใน HTML เดิม — ให้เป็น spec ใช้ได้จริง ไม่ใช่แค่ไอเดีย
