# Gochisou TikTok — สคริปต์ Batch 1

> ตัดสินใจ 29 ส.ค. 69 (Gemini_Advice_Sales_Strategy): 1 ช่อง Gochisou (อาหารญี่ปุ่น/เคสจองจริง)
> top-funnel → LINE/เว็บ — เริ่มเมื่อมีคอนเทนต์ 5-10 คลิปพร้อม. เริ่ม Batch 1 = 5 คลิป 2 ก.ย. 69.
> ช่องจอง: LINE `https://line.me/ti/p/30vpsvVCjS` · เว็บ `https://gochisou.ichinotour-thailand.com/`

## ข้อเท็จจริงที่ต้องเขียนให้ตรง (ห้ามเกินจริง)

- บริการ: รับจองร้านอาหารทั่วญี่ปุ่น — ร้านดัง/จองยาก (sushi omakase, shabu/食べ放題, yakiniku, ฯลฯ)
- ค่าบริการจอง: กรุ๊ป ≤40 = 3,000 JPY · 40+ = 5,000 JPY ต่อร้าน/ต่อการจอง — คิดเฉพาะจองสำเร็จ
- เวลาทำการ: 09:00-18:00 (JST) — งาน Land Operator ในญี่ปุ่น (Ichinotour)
- ใช้ได้จริง: กรุ๊ปเดินทางเอง (กลุ่มเพื่อน/ครอบครัว) และบริษัททัวร์ (B2B)
- ห้าม: ข้อมูลลับ/ราคา margin/ตัวตนลูกค้า (AGENTS §16); อ้าง "จองได้ทุกที่ 100%" — ไม่จริง, ใช้ "ช่วยเช็ค/ช่วยจัดการ" แทน

## Format วิดีโอ (ทุกคลิป)

- แนวตั้ง 9:16, ยาว 20-35 วิ
- Hook 0-3 วิ = ปม/คำถาม (กันสไลด์)
- กลาง = ปม + ทางออก (ภาพอาหาร/ร้านจริง)
- จบ = CTA "ทัก LINE" + หน้าเว็บ
- เสียง: voiceover ไทย (พี่เจอ่านเอง หรือ TTS) + เพลงสั้น background
- ภาพ: gen ด้วย Gemini Omni (labs.google, บัญชี chettana33) — prompt ตัวอย่างต่อคลิป; ถ้า Omni ยังไม่ทำ voiceover ไทย/ซับ ให้ gen แบบภาพ + ฝังข้อความ แล้วพี่เจ over-dub ภายหลัง
- Caption บนจอ: ข้อความสั้น 4-8 คำ/จอ (ให้อ่านใน 1-2 วิ)

## คลิป 1 — "ร้านดังในญี่ปุ่น จองยากกว่าที่คิด"

**ปม:** omakase/sushi ร้านติดดาว ต้องโทรญี่ปุ่น ภาษา ระบบสมาชิก → คนไทยจองไม่ได้

**โครงสร้าง:**
- Hook (0-3 วิ): "ร้านซูชิดังในโตเกียว ทำไมจองยากกว่าตั๋วคอนเสิร์ต?"
- กลาง: ภาพ omakase + ข้อความ "โทรญี่ปุ่น ภาษาญี่ปุ่น สมาชิกเท่านั้น" → "เราอยู่ญี่ปุ่น จัดการแทนคุณ"
- จบ: "จองร้านดังญี่ปุ่น → ทัก LINE ฟรี ไม่จองสำเร็จไม่คิดเงิน"

**VO (คำต่อคำ):**
"ร้านซูชิร้านดังในโตเกียว… จองยากกว่าตั๋วคอนเสิร์ตอีก เพราะต้องโทรไปญี่ปุ่น พูดญี่ปุ่น หรือบางร้านรับเฉพาะสมาชิก เราเป็นทีม Land Operator อยู่ญี่ปุ่นจริง ๆ จัดการจองให้คุณ ทั้งร้านซูชิ ชาบู ยากินิกิ ร้านที่จองยากก็ลองได้ ไม่สำเร็จไม่คิดค่าบริการ ทัก LINE มาคุยก่อนได้ฟรี ๆ"

**Omni prompt (ภาพ):**
```
Vertical 9:16 video. Close-up of premium sushi omakase being plated by chef's hands
with gold leaf, dark moody Michelin restaurant, then cut to a smartphone showing a
Thai LINE chat with a booking confirmation. Warm red/gold/charcoal color grade.
No readable real text. Fast food-vlog energy.
```

**Caption จอ:** "จองยากกว่าตั๋วคอนเสิร์ต" → "เราอยู่ญี่ปุ่น จัดการแทน" → "ทัก LINE ฟรี"

**คำโปรยโพสต์:** ร้านดังที่จองยาก ลองให้ทีมญี่ปุ่นช่วยยิงธนูดู มือใหม่ก็กินร้านเทพได้ #เที่ยวญี่ปุ่น #ร้านดังญี่ปุ่น #japanfood

## คลิป 2 — "กรุ๊ป 27 คน อยากกินชาบูญี่ปุ่น จองได้ไหม?"

**ปม:** กรุ๊ปใหญ่ ร้านดังรับจองน้อยที่นั่ง → กินไม่ได้ (อิงเคสจริง: กรุ๊ป 27 Tokyo)

**โครงสร้าง:**
- Hook: "กรุ๊ป 27 คน จะกินชาบูร้านดังในโตเกียว… ร้านรับไหม?"
- กลาง: ภาพชาบู/食べ放題 (しゃぶよ/すたみな太郎 สไตล์) + "ร้านกลุ่มไม่รับจองผ่านเว็บต่างชาติ แต่รับจองผ่านบริษัทญี่ปุ่น"
- จบ: "จองกรุ๊ปใหญ่ ร้านดัง → ทัก LINE"

**VO:**
"กรุ๊ป 27 คน ไปกินชาบูที่ญี่ปุ่น หลายร้านดี ๆ รับจองแต่กรุ๊ปผ่านบริษัททัวร์ในญี่ปุ่นเท่านั้น จองเองผ่านเว็บนอกไม่ได้ เราเป็น Land Operator อยู่ญี่ปุ่น จัดการจองกรุ๊ปใหญ่ให้ได้ ทั้งชาบู ยากินิกิ อาหารเซ็ตใหญ่ บอกจำนวนคน วันเดินทางมา เราช่วยเช็คร้านที่รับจริง ทัก LINE มาวางแผนกัน"

**Omni prompt (ภาพ):**
```
Vertical 9:16 video. Big group of happy Thai friends at a Japanese shabu-shabu
restaurant, hot pot boiling, platters of meat and vegetables on the table, staff
in Japanese uniform serving. Confetti of booking confirmations. Warm appetizing
light. No readable real text.
```

**Caption จอ:** "กรุ๊ป 27 คน จองร้านใหญ่ไม่ได้?" → "Land Ops ญี่ปุ่นช่วยได้"

**คำโปรย:** กรุ๊ปใหญ่ จองร้านดังชาบูไม่ต้องกลัวร้านปัด #เที่ยวญี่ปุ่นกรุ๊ป #ชาบูญี่ปุ่น #eatall

## คลิป 3 — "เที่ยวเองก็กินร้านดังได้ ไม่ต้องซื้อทัวร์"

**ปม:** นักเที่ยวอิสระ คิดว่าจองร้านดังต้องมากับทัวร์เท่านั้น (อิงเคส: เดินทางเอง Fuji 20 / Tokyo 2)

**โครงสร้าง:**
- Hook: "เที่ยวญี่ปุ่นเอง… กินร้านดังไม่ได้ จริงเหรอ?"
- กลาง: ภาพทริปเที่ยวเอง + ร้านอาหาร + "บริการจองร้าน ใช้ได้กับคนเดินทางเอง"
- จบ: "จองเฉพาะร้าน ไม่ต้องซื้อทัวร์ทั้งทริป → LINE"

**VO:**
"หลายคนเข้าใจว่า อยากกินร้านดังต้องมากับทัวร์ ผิด! เราจองร้านให้คนเดินทางเองด้วย บอกวัน เดินทาง เมือง จำนวนคน เราจัดการให้แค่ส่วนของร้าน ไม่ต้องซื้อทัวร์ทั้งทริป จองสำเร็จค่อยจ่าย เป็นค่าบริการจองต่อร้าน ไม่ใช่ค่าอาหาร ทัก LINE ส่งแผนเที่ยวมา เราช่วยเช็คร้านให้"

**Omni prompt (ภาพ):**
```
Vertical 9:16 video. Independent Thai traveler with small backpack walking Tokyo
street at dusk, lanterns, then transition to sitting at a premium izakaya counter
with sashimi and sake, phone showing Thai LINE chat with restaurant reservation.
No readable real text. Cozy travel-vlog feel.
```

**Caption จอ:** "เที่ยวเอง… กินร้านดังได้" → "จองแค่ร้าน ไม่ต้องซื้อทัวร์"

**คำโปรย:** เที่ยวเองก็ปัง กินร้านดังไม่ต้องรอทัวร์ #เที่ยวเองญี่ปุ่น #ไปญี่ปุ่น #japantravel

## คลิป 4 — "ภาษาไม่เก่ง จองร้านดังที่ต้องโทรเท่านั้น"

**ปม:** ร้านดังหลายร้าน รับจองทางโทรศัพท์ญี่ปุ่นอย่างเดียว → ต่างชาติตกเครื่อง

**โครงสร้าง:**
- Hook: "ร้านนี้รับจองทางโทรศัพท์เท่านั้น… แล้วคนไทยจะโทรไปทำไม?"
- กลาง: ภาพร้าน + ภาพโทรศัพท์ + "ร้านแถวนี้ต้องการคนในพื้นที่คอนเฟิร์ม"
- จบ: "เราคุยญี่ปุ่นกับร้านให้ → LINE"

**VO:**
"ร้านดังหลายร้านในญี่ปุ่น รับจองแค่โทรศัพท์ ไม่มีระบบออนไลน์ โทรไปก็คุยญี่ปุ่นไม่รู้เรื่อง แถมบางร้านต้องคอนเฟิร์มอีกทีก่อนวัน เราเป็นทีมคนไทยที่ทำงานอยู่ญี่ปุ่น คุยกับร้านให้ทั้งตอนจองและตอนยืนยัน มีปัญหาอะไร แก้ให้ได้หน้างาน ทัก LINE แล้วให้รายละเอียดทริปมา เราเหลือเรื่องคุยกับร้านให้"

**Omni prompt (ภาพ):**
```
Vertical 9:16 video. Old-school Japanese restaurant entrance with noren curtain,
phone in hand, Japanese text on wall blurred/unreadable. Split screen: confused
Thai tourist vs cheerful Thai agent in office with headset nodding. Cut to
restaurant interior with chef bowing welcome. No readable real text.
```

**Caption จอ:** "รับจองทางโทรศัพท์เท่านั้น" → "เราคุยญี่ปุ่นให้"

**คำโปรย:** ร้านรับโทรอย่างเดียว? เรื่องภาษาเราจัดการ #ร้านดังญี่ปุ่น #ไปเที่ยวญี่ปุ่น #foodies

## คลิป 5 — "ร้านดัง 3 แบบ ที่คนไทยพลาดบ่อย"

**ปม:** รวมความรู้: (1) omakase สมาชิก (2) ร้านรับเฉพาะท้องถิ่น (3) ร้านต้องคอนเฟิร์มล่วงหน้า → พลาดเพราะไม่รู้

**โครงสร้าง:**
- Hook: "3 ร้านแบบนี้ คนไทยพลาดบ่อยที่สุดตอนเที่ยวญี่ปุ่น"
- กลาง: 3 จอเร็ว (omakase / ร้านนอกเมือง / ยากินิกิต้องคอนเฟิร์ม) + ข้อความบอกปมแต่ละแบบ
- จบ: "ไม่อยากพลาด → ให้ทีมญี่ปุ่นเช็คให้ก่อนตัดสินใจ → LINE"

**VO:**
"ร้าน 3 แบบที่คนไทยมักพลาด ร้านแรก omakase ที่รับจองเฉพาะสมาชิก ร้านสอง ร้านอร่อยนอกเมืองที่ไม่มีเว็บต่างชาติ ร้านสาม ยากินิกิร้านดังที่ต้องโทรคอนเฟิร์มก่อนวัน เราเจอปัญหาเหล่านี้ทุกวัน เพราะทำงานอยู่ญี่ปุ่น ก่อนไปเที่ยว ทัก LINE ให้เราช่วยเช็คว่าร้านที่อยากกิน จองได้จริงไหม เสียเวลาคุยกับเรา ดีกว่าพลาดตอนอยู่หน้าร้าน"

**Omni prompt (ภาพ):**
```
Vertical 9:16 video. Fast montage of three restaurant types: 1) omakase sushi
counter with chef, 2) countryside restaurant exterior in scenic town, 3) yakiniku
grill with staff on phone. Each shot with bold Thai subtitle card. Energetic
food-tok pacing, warm red/gold grade. No readable real text.
```

**Caption จอ:** "1 สมาชิกเท่านั้น" "2 ไม่มีเว็บต่างชาติ" "3 ต้องโทรคอนเฟิร์ม"

**คำโปรย:** เช็คก่อนไป ร้านที่อยากกินจองได้จริงไหม #เที่ยวญี่ปุ่น #foodtok #ร้านเด็ดญี่ปุ่น

## กติกาการลง + ต่อ Batch 2

- โพสต์: ลงคลิป 1-2 ต่อสัปดาห์, เวลาไทย 18:00-20:00 (คนดู peak), bio ช่อง = "จองร้านดังญี่ปุ่น 🇯🇵 ทัก LINE" + ลิงก์ LINE
- ถ้า Omni gen ไม่รองรับซับไทย/voiceover: gen ภาพ+บรรยากาศ แล้วพี่เจบันทึกเสียง VO ทับ (อ่านจาก VO ข้างบน) — ซับตัดใน CapCut/แอปฟรี
- หลังคลิป 1 ขึ้น: ดู retention (hook 3 วิ) — คลิปไหน retention < 40% ให้แก้ hook ก่อน
- เคสจริงใหม่ (จาก quotations) → Batch 2 — ใช้แต่ข้อมูลที่พี่เจอนุมัติ, anonymize เสมอ
- ก่อนจองจริง/โปรโมตราคา: พี่เจ confirm ข้อเท็จจริงราคา (3,000/5,000 JPY) บน landing ตรงกันก่อน
